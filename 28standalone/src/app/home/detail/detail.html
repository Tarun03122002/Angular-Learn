Standalone componnet

Standalone component if using any depenedency ,then it must import that depenendncy in that standalon ccomponent

Standalone component can be used together with normal components or inside ngModule but their motive is to get rid of NgModule, so that our boiler platecode of ngModule will not get increased.Also if decalartion,import ,exports issue in ngModule,then app will not work.This the amin reason to introduce Standalone componentS.
